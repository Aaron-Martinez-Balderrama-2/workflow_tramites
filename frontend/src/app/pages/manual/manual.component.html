⚙️ Uso del Sistema

Bienvenidos a PolicyFlow AI

PolicyFlow AI es una plataforma avanzada de gestión de procesos de negocio (BPM) potenciada por Inteligencia Artificial Local. Este sistema permite modelar, ejecutar y supervisar trámites complejos de manera eficiente y segura.

IA Local

Privacidad total. Todo el procesamiento de IA ocurre en tus propios servidores usando Ollama.

BPMN 2.0

Estándar internacional para el modelado de procesos de negocio.

Manual para Administrador

Gestión de Seguridad y Usuarios

Como administrador, usted es el responsable de mantener la integridad y seguridad del sistema.

Control de Usuarios: Desde el panel de Administración, puede crear, editar y dar de baja usuarios, asignándoles roles específicos (Administrador, Diseñador, Funcionario).

Configuración de Áreas

Defina las áreas de trabajo o departamentos. Cada área permitirá agrupar funcionarios y asignarles tareas específicas según su jurisdicción.

Manual para Diseñador

Modelado Asistido por IA

El diseñador utiliza el lienzo BPMN para dar vida a las políticas de negocio. Gracias al asistente Ollama AI, puede editar diagramas usando lenguaje natural.

Comandos de Voz/Texto: "Borra la tarea de revisión", "Crea un inicio llamado Solicitud", "Añade un carril para Legal".

Publicación de Trámites

Una vez finalizado el modelo, utilice el botón "Generar Sistema" para convertir el dibujo en un trámite funcional que los funcionarios puedan ejecutar.

Manual para Funcionario

Gestión de Trámites Activos

El funcionario es el motor operativo del sistema. Su labor es completar las tareas asignadas a su área.

Bandeja de Entrada: Revise los trámites pendientes, abra los detalles y complete los requisitos solicitados para avanzar el flujo.

El sistema notificará automáticamente al siguiente responsable cuando usted complete su labor.

Manual de Uso General

Interfaz de Usuario

PolicyFlow AI cuenta con un diseño adaptable y modo oscuro integrado.

  • Barra Lateral: Navegación principal entre módulos.
  • Cambio de Tema: Use el icono de sol/luna en la cabecera para alternar entre temas.
  • Seguridad: El sistema cierra sesión automáticamente tras periodos de inactividad para proteger los datos.
